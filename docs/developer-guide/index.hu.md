# Fejlesztői dokumentáció

Ez a fejezet a rendszer fejlesztői szempontú bemutatását tartalmazza. Célja, hogy átfogó képet adjon az alkalmazás felépítéséről, a választott technológiákról, valamint a megvalósítás során alkalmazott architekturális döntésekről.

A fejezet bemutatja a rendszer tervezési folyamatait, a backend és frontend komponensek működését, valamint a deployment és tesztelési megoldásokat.
