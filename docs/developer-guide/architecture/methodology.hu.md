# Fejlesztési módszertan

A fejlesztés egyszemélyes projektként zajlott, formális sprint struktúrával kezdődött, ezek trekkeléséhez felállítottam egy saját Vikunja klienst is. A projekt előrehaladtával átálltam vízesés fejlesztési modellre.
