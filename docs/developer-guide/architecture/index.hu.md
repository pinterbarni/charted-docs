# Rendszerarchitektúra

A rendszer egyszemélyes projektként indult, amelyben a teljes infrastruktúra, a backend és a mobilalkalmazás fejlesztése egyetlen fejlesztő kezében volt. Ez a körülmény meghatározta az architekturális döntéseket: a cél egy olyan rendszer kialakítása volt, amely egyszerre kezelhető és a jövőben bővíthető.
