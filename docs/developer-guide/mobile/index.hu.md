# Mobil alkalmazás

A Charted mobilalkalmazása React Native alapokon, Expo keretrendszer segítségével készült, és iOS, valamint Android platformon is futtatható. Ez a fejezet bemutatja a felhasznált technológiákat, az EAS alapú fejlesztési és build folyamatot, a navigáció és a képernyők felépítését, a térképintegrációt, az útvonalkezelést, a túrarögzítést és GPS követést, az állapotkezelést, az offline funkciókat, a design rendszert, valamint a lokalizációt.
