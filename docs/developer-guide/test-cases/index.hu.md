# Tesztesetek

--8<-- "web-addition.hu.md"

Az alkalmazás funkcióinak ellenőrzésére szolgáló tesztesetek GIVEN, WHEN, THEN formátumban kerültek leírásra: minden lépés megadja a kiinduló állapotot, a felhasználói műveletet és az elvárt eredményt. A tesztesetek funkcionális területek szerint vannak csoportosítva, összesen 56 tesztesettel és 170 lépéssel.
