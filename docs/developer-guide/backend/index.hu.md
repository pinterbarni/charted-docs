# Backend

A rendszer háttérrendszere egy NestJS alapú BFF (Backend for Frontend), amely a mobilalkalmazás és a mögöttes szolgáltatások között helyezkedik el. Ez a fejezet bemutatja a felhasznált technológiákat, a modulstruktúrát, az adatbázis modellt, az autentikáció működését, az API végpontokat, a gamifikációs logikát, a külső szolgáltatásokat elérő proxy modulokat, valamint a kódminőség biztosításának eszközeit.
