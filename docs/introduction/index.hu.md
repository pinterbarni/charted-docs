# Bevezetés

Szakdolgozati témám egy keresztplatformos túraalkalmazás tervezése és megvalósítása volt, amelyet React Native és Next.js technológiák felhasználásával készítettem el. A fejlesztés során célom egy olyan modern, skálázható és több platformon is használható rendszer létrehozása volt, amely képes támogatni laikus túrázók igényeit, miközben a fejlesztési folyamat során szerzett tapasztalataim is bővülnek.

A dolgozat középpontjában egy saját fejlesztésű alkalmazás áll, amely mobil eszközökön elérhető.
